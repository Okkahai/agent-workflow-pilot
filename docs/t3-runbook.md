# T3 controller runbook

Keep universal policy in engineering-standard.md. Default: coordinator plus one implementer when useful, then one independent reviewer. Parallel workers require disjoint ownership. Coordinator alone merges.

1. Inspect instructions, git status, remote, locks and CI. Call `orchestrator_capabilities({})` once before delegation. Do not silently substitute an unavailable provider. Commit the task brief first: uncommitted edits do not enter child worktrees.
2. Call `delegate_task({role:"implementation", isolation:"worktree", mode:"async", task:"Read AGENTS.md and docs/plans/TASK.md; implement scope, run checks, create and link PR; return URL, head, tests and limitations; do not merge or spawn agents."})`. T3 creates the checkout; do not make a shell checkout for it. Save taskId/link. Follow returned next: end turn for completion wake, never poll. Cancel abandoned work with task_cancel. One directory and branch per writer.
3. Inspect returned diff and head. Read referenced threads with `t3_thread_read({threadId:ID, limit:5})`. Immediately link created/taken-over/pushed PRs with `link_pull_request({url:URL})`. Start a new `delegate_task({role:"review", mode:"async", task:"Read-only review PR URL at exact SHA in PATH against task requirements; run checks; report findings and reviewed SHA; no edits, merge or subagents."})`. Shared checkout review is safe only while writers are idle. Corrections invalidate the review: create a fresh review task. AI review is not GitHub approval.
4. Collect `gh pr view NUMBER --json headRefOid,baseRefOid,mergeStateStatus,statusCheckRollup,reviewDecision,reviews`; inspect `gh api repos/OWNER/REPO/rules/branches/BASE`, classic `branches/BASE/protection`, individual applicable rulesets and repository permissions. Check inherited policy, required check source apps, approvals and bypass. Classic 404 alone proves nothing. Inaccessible or incomplete protection, missing permission or unsupported policy blocks: report endpoint/status, never change protection to proceed. Fetch base and inspect ancestry; reconcile staleness normally, test and re-review.
5. Run the normalized gate contract in engineering-standard.md with freshly collected trusted evidence. Recollect head/base and CI before `gh pr merge NUMBER --squash --match-head-commit FULL_SHA`, never admin or delayed auto-merge based on stale review. Honor merge queues where applicable; unsupported rules block. For pending checks/review call `watch_pull_request({url:URL})` and end turn; a wake triggers inspection, not automatic eligibility. Read back mergedAt/mergeCommit after success and unwatch before final handback.
