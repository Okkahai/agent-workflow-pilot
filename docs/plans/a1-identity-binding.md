## Design

Add one minimal versioned external binding adapter at Program/Delivery entry boundaries, referencing unchanged immutable legacy binding/checkpoint and relevant source hashes. Reuse strict JSON, SHA, M1 and checkpoint validators. Do not create another state machine or project registry.

Separate project ID, host-qualified or opaque repository identity (not universally GitHub owner/name), physical checkout association, logical task, native attempt and approval reference/provenance. Expectations are supplied independently by the trusted controller, never derived from the envelope being validated. Independently observe actual Git root, worktree association, common directory and origin using bounded safe Git reads. Compare to explicitly supplied approved checkout facts; names/hashes alone do not prove a root. Handle canonical Windows aliases/case/redirects carefully; unsupported or ambiguous observations block. GitHub remote identity is the initial verifiable host case; other host/local identity may be represented but must explicitly block unsupported verification, not claim tested adoption.

Approval reference binds source/type, project/repo/task/scope, plan/spec revisions, allowed implementation operation and current valid/non-revoked/non-superseded status to independently available controller evidence. Explicit current user decision can authorize unmerged work. Designated trusted policy allowed only when controller-authorized. JSON/PR flags/agent summaries cannot authenticate permission; implementation approval never grants merge. Return inert validation results with authorizes=false; controller supplies trust, adapter checks consistency and rejects absent trusted provenance.

Legacy v1 remains byte-preserved: Program binding, checkpoint, M1 context, handoff, routing sidecar, continuation receipts. Identity envelope must be checked BEFORE project-scoped operational state consumption. Prevent accidental bypass through Program/lifecycle/continuation CLI alternatives in explicitly project-scoped mode; define and test mode selection so missing binding fails closed. Legacy pilot mode remains explicitly documented, not advertised multi-project safe. Do not silently change fingerprint domains, retries, task/native IDs or migrate archives. Relocation/rebind unsupported; reject unexpected moved root. Rollback retains uncertain state.
